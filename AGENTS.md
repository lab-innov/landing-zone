# Instrucciones para agentes

Antes de modificar infraestructura Bicep, leer [la guía para agentes](docs/guia-agentes-bicep.md).

- Mantener toda la documentación en español y los README breves.
- Aplicar los acuerdos de CAF y las restricciones de infraestructura documentadas para el spoke correspondiente.
- Confirmar repositorio, rama y worktree antes de editar; preservar cambios ajenos.
- Registrar los avances propios en commits locales con mensajes simples en español. No hacer push a Git sin autorización; en este trabajo sigue vigente la instrucción de no hacer push.
- Cuando se modifique una aplicación de Container Apps, publicar su imagen actualizada en el registro de contenedores correspondiente y registrar la versión publicada. Esto no equivale a hacer push a Git ni autoriza por sí solo un despliegue en producción.
